# Hardware files

The current assembly and drivetrain CAD are in **[Onshape](https://cad.onshape.com/documents/9a8c18891301aa8b92cf775c/w/e2064653b9b5e6534297f6f2/e/1f7830fac36eec9a8cd147fd)**. Start with the [CAD guide](cad/README.md) for model coverage and file formats.

I kept my original bracket exports, chair models, and scans here alongside the drivetrain spreadsheet.

| Path | Purpose |
| --- | --- |
| [bill-of-materials.xlsx](bill-of-materials.xlsx) | My drivetrain calculations and comparisons |
| [cad/README.md](cad/README.md) | Current Onshape assembly, preview, and CAD navigation |
| `cad/mounting-bracket/` | Printable 3MF plus OBJ/MTL bracket exports |
| `cad/chair-model/` | Rio 2 chair reference in Blender, OBJ, and USDZ formats |
| `cad/photo-scan/` | Cleaned photogrammetry model plus raw textured scan |
| `cad/true-depth-scan/` | Alternate TrueDepth scan |
| `cad/vex-parts/` | VEX washer STEP model used during CAD work |

Blender `.blend1` files are automatic backups included in the supplied archive. OBJ files should stay beside their MTL and texture files so material references continue to resolve.

I used the scans to check the fit around the chair. Measure your chair before drilling or printing a bracket.
