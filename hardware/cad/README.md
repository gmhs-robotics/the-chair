[![Drivetrain and support-frame CAD preview](../../media/images/cad-overview.webp)](https://cad.onshape.com/documents/9a8c18891301aa8b92cf775c/w/e2064653b9b5e6534297f6f2/e/1f7830fac36eec9a8cd147fd)

I modeled the chair and drivetrain in Onshape. Open the link to explore the assembly, then use the tabs along the bottom to look at individual parts and subsystems. You can view it without signing in.

| Onshape tab | What to inspect |
| --- | --- |
| The Chair | Top-level chair and drivetrain assembly |
| Chair Drivetrain | Wheelbase and support structure |
| Drivetrain Side | One side of the differential drivetrain |
| Motor+Gear | Motor and gear assembly |
| Wheel | Wheel assembly |
| CAD Imports | Imported reference geometry |
| 1/2" Spacer Screw; Steel Washer (275-1024) | Component references |

I posted this wheelbase and frame preview in my [Stardance CAD devlog](https://stardance.hackclub.com/projects/4170). The Onshape link opens my live workspace.

## Local reference files

| Folder | Contents and intended use |
| --- | --- |
| [mounting-bracket](mounting-bracket/) | Printable 3MF and OBJ/MTL exports of the seat mounting bracket |
| [chair-model](chair-model/) | Rio 2 reference geometry in GLB, Blender, OBJ, and USDZ |
| [photo-scan](photo-scan/) | Photogrammetry models and raw textured scan |
| [true-depth-scan](true-depth-scan/) | Alternate chair scan |
| [vex-parts](vex-parts/) | Washer STEP reference |

I used the scans and exports to check fit during the build. Check dimensions against your chair before making parts. Keep OBJ, MTL, and texture files together. Blender `.blend1` files are my archived automatic backups.
